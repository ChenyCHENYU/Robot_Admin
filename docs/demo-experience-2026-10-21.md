## 两个根因修复

- 图编辑的 SVG 声明了 `font-size="12"`，UnoCSS 属性模式却生成 `[font-size~="12"] { font-size: 3rem }`，导致实际文字变为 48px。配置现已排除 SVG 原生展示属性，同时保留页面的文本和间距工具类；逻辑测试直接验证生成 CSS，浏览器再次核对实际字号。
- 原 PDF 阅读器使用 Blob iframe，部署策略与浏览器插件环境会阻止内容显示。新阅读器直接在本机解析和绘制，并释放旧文档与渲染任务；严格的 `object-src 'none'`、原有 `frame-src` 保持不变。浏览器验收还检查正文的深色像素，防止把空白画布或仅有装饰线误判为预览成功。

## 验证范围

运行 `bun run verify`，覆盖双 Lint、样式边界、应用和组件类型、逻辑与组件测试、演示与应用双模式构建，以及原有首屏资源预算。

浏览器使用正式产物，覆盖十个页面的浅色／深色与 1657px／768px 布局，以及以下真实交互：

- 真实部署 CSP 下读取中文 PDF、翻页、缩放及损坏文件恢复。
- 在线瓦片服务实际加载；另用隔离网络 fixture 验证底图失败后切换和标记保留。
- 离线人员头像、审批方式回写、三个图场景的节点与关系、只读预览。
- 解包 ZIP 核对源文件、配置及报表；下载 XLSX 后重新导入；下载 PDF 后再次阅读。
- 视频切源、清空和恢复，聊天会话及本地附件，切页后的样式隔离。

外部地图与公开视频仍受访问者网络和服务可用性影响；验收记录区分真实服务检查与故障 fixture，不将模拟响应当作线上可用性证明。
