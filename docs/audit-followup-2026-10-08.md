# 关于页修复与复扫核对

核对基线为 `ca73e82`。范围为 Robot_Admin，自身规范及现有线上生态包；未接入 wl-skills-kit，也未修改 Wl 项目。报告的“85%”属于主观完成度估计，以下按可验证的具体发现判断。

## 关于页依赖列表空白

浏览器复现时，两组表格各有 10 行 DOM，但 `.n-data-table-base-table-body` 高度为 **0px**。`C_Table` 明确使用 `inheritAttrs: false`，把传入的 class 转发到内部 `NDataTable`；页面 scoped 的高度类没有命中该内部节点。开启 flex-height 后，缺少实际高度的滚动区将内容裁掉。依赖计数、表头和分页器仍然存在，因此之前只检查行数和分页位置的测试没有覆盖到这个缺陷。

修复由页面提供自身的固定高度容器，在该容器内完整建立表格与分页的 flex 高度链，不修改全局样式或覆写数据。实际滚动区恢复到约 394px，整组占用 480px，末页、搜索少量结果和空结果保持布局稳定。新增浏览器检查覆盖两组依赖的行数、视口内绘制、单元格命中、末页以及搜索清空。

## 验收

移除写死代理后的完整浏览器回归暴露了额外问题：展开与动态表格演示仍直接请求 employees 接口。两页已接入 request-core 已有的内存数据源，复用原来的演示样例并隔离各实例；真实远端模式保留 API 地址，不静默回退。补充实例隔离与 CRUD 测试，并验证展开子表的异步加载状态。

- `bun run verify`：静态检查、类型、样式边界、150 个单测、演示和业务生产构建、体积预算通过。
- 新增适配器测试验证草稿快照、查询隔离、重复账号、CRUD、公司过滤、停用与登录目录同步及取消请求。
- 关于页真实浏览器测试通过：两组依赖内容、末页和空结果高度、搜索、主题切换及窄屏无溢出。
- 首次完整浏览器回归 173 项通过、3 项按环境跳过；包括 90 路由连续绘制、导航搜索、错误页及各布局主题。发现的关于页检查假设和员工演示接口依赖均已处理，随后受影响的 68 项分组复测全部通过，覆盖关于页、统一表格及加载态、用户/角色/权限表单、公司切换及生产 CSP。子表测试先等待启动遮罩退场再冻结时钟，避免本地数据立即返回后将启动遮罩冻结。
- MCP 使用真实 stdio 客户端查询组件 API 与验证规则，未只检查源码字符串。

提交前使用本项目 convention-audit 技能复核，并修正其过期的自动导入及 API 契约检查口径：领域 Store 和页面控制器显式导入，响应类型可位于资源 contract 文件。

现有上游安全审计未因此消失，生产文档保留其边界；本次没有通过关闭校验或吞掉日志制造通过结果。应用仍消费线上组件库 0.14.2，没有本地包替换。
