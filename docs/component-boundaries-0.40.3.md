# 组件库 0.40.3 接入验收

2026-11-15，基于应用 `549e91a` 的隔离分支，将正式依赖从 0.40.2 精确升级到 0.40.3。安装版本和锁文件 integrity 与官方发布包一致。MachTable 0.42.0、request-core 0.7.0 及其锁记录保持不变，业务页面未改动。

## 分块与预算

| 指标               | 0.40.2 构建 | 0.40.3 构建 |
| ------------------ | ----------: | ----------: |
| modulepreload 数量 |          90 |          91 |
| 首屏资源合计       | 1,262,733 B | 1,263,451 B |
| 入口 JS            |    73,851 B |    73,851 B |
| CSS                |   306,726 B |   306,726 B |
| 最大异步块         | 2,410,911 B | 2,410,911 B |

新增的一个共享块来自原有 locale 字典拆出：旧语言 hook 为 18,684 B，新 hook 为 231 B，公共 locale 块为 18,680 B。主要是既有代码迁移，首屏总量仅净增 718 B，没有将上传专属词表或新 SDK 提前加载。

因此仅将预加载数量基线调整为 91，入口、预加载、CSS、首屏总量及最大异步块的字节限额全部保留。没有为此匹配组件库私有文件名或改写应用分包策略。预算解析和判定的 3 项既有回归继续通过。

验证使用隔离分支的正式依赖和构建产物，不使用本地包别名；主工作区其他任务的未提交表格与测试修改不计入本次验收。GitHub 账户账单限制仍需账户侧处理，不能将未启动的远端任务记作通过。
