# 组件库 0.18.0 类型契约与接入验收

本轮将组件回调、插槽和公开实例的类型维护收回包内。业务接口留在应用，字段名和值由组件关联检查；请求包同步升级到 0.6.3，组件库与请求包之间不新增运行时依赖。

## 接入变化

| 场景             | 使用方式与边界                                                                                                                                                                  |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 表单             | 使用 `defineFormOptions<Model>`；初值和 `valueWhen` 与字段类型关联。嵌套、数组和递归模型支持六层字段路径，空对象仍可作为动态模型。已验证 TypeScript 5.8，不要求应用升级编译器。 |
| 搜索             | 从完整 `v-model` 推导查询模型；请求函数可直接作为 `config.onSearch`。文本、单选、多选和日期分别按真实空值重置，保留隐藏字段及未配置的业务上下文。                               |
| 表格与展开子表   | 列配置直接交给 CRUD；移除应用内 `toCrudTableColumns`。使用 `TableConfig<Row, Child>`，子记录与选择状态不再由应用断言。                                                          |
| 动态行           | 具体业务模型提供 `dynamicRows.defaultRowData`，返回完整新行和唯一主键。组件保留数字或字符串主键，拒绝无效及重复身份；关闭仍可用 `false`。                                       |
| 树、拖拽与穿梭框 | 普通业务接口直接参与推导；管理页使用 `TreeExpose<Node>`。回调和插槽保留业务字段与键类型。                                                                                       |
| 日期与时间       | 优先标准 `v-model`；静态模式区分单值与范围，动态及可选模式保留真实联合。旧别名继续兼容。                                                                                        |
| 工作流与图编辑   | 节点数据按 `node.type` 缩窄；使用包提供的 `WorkflowExpose`、`DiagramExpose`。                                                                                                   |
| 甘特图           | 配置、事件和布局回调采用准确 SDK 契约。任务日期反映 SDK 编辑后的 `string \| Date`，子记录不虚称具有父记录独有字段；同构任务模型显式声明同构 `children`。                        |

应用删除了列转换工具、重复的实例接口、事件参数断言和宽泛索引继承。复杂组件保持按需加载，业务模型不为了通过编译继承开放索引。

## 验证范围

- 组件库完整验证：333 条核心测试、315 条挂载测试；源码、真实 Vue 模板及发布声明的 ESM/CJS、Node16/NodeNext 检查通过。额外使用应用的 TypeScript 5.8.3 验证消费契约。
- 应用完整验证：257 条核心测试、109 条挂载测试；样式边界、类型检查、演示版与 application 两套生产构建、资源预算通过。
- 浏览器 27 条核心回归通过：搜索与表单密度、状态 0、三种表格编辑、展开间距、子表选择、动态增删复制、树受控与虚拟化、代码草稿及 Markdown 保存恢复。另有甘特搜索与选择、穿梭框预览与撤销两项通过。
- 显式 `any` 从 157 减到 117，质量预算同步收紧；未放宽包体与按需加载预算。

组件库 0.18.0 与 request-core 0.6.3 已正式发布，匿名下载的 SHA512 均与本地验证归档一致。应用使用精确 registry 版本，锁文件不包含临时路径；正式安装后的 TypeScript 5.8.3、版本契约和冻结锁文件离线安装继续通过。

已有全项目 lint 提示与供应商构建提示继续保留，不能据此宣称项目没有后续优化空间。后续由真实业务问题和性能测量驱动改进。
