# 工程分析与使用统计

分析页读取当前源码、安装版本、每次构建生成的 `project-metrics.json` 和浏览器 Performance API。统计页显示实际访问与明确埋点的事件，默认数据范围是当前浏览器。两个页面没有预置流量、营收、订单或增长率。

## 数据口径

- Vue 文件数包含 `src/views` 下的页面和子视图；菜单数量是仓库菜单清单的叶子项，不是当前账号的授权菜单数量。
- 组件数来自已安装业务组件包的公开声明；依赖分布统计项目的直接生产与开发依赖，不把数量当作包体积。
- 首屏体积来自构建 HTML 的入口、预加载 JS 与 CSS；产物地图包含异步 JS。gzip 是压缩估算，不是实际传输量。
- 编译耗时从 Vite `buildStart` 到产物写入阶段，不包含安装依赖、部署或开发服务器冷启动。
- TTFB、FCP、DOM Ready 以当前文档导航为原点；挂载完成是自定义标记，不代表 TTI。加载时间轴中的区间可能重叠，不能直接相加。
- 页面 PV 只统计成功导航。重复路由、查询参数变化、失败导航不新增 PV；重新加载文档会新增访问。
- 页面 P50 / P95 是组件解析到导航首帧的耗时，不包含该守卫之前的认证或菜单请求，也不是用户停留时长；无样本保持未知。
- 登录成功在完整公司会话和权限路由就绪后计数，恢复已有会话与刷新 Token 不计为新登录。演示认证会标注 `mock`，远端认证标注 `remote`，可以筛选。
- 本机保留最近 7 天、最多 1000 条记录，使用随机匿名标签页会话 ID，统计的是会话而非独立用户。不同浏览器和设备的数据只有接入统一服务才会汇总。

## 扁平配置

项目配置在 `src/config/observability.ts`。可通过部署环境设置：

```dotenv
# 默认 true，仅本机记录；false 同时停止本机与本插件的外部事件采集。
VITE_OBSERVABILITY_ENABLED=true

# 默认留空：不会向服务器发送埋点，也不会发起全站汇总查询。
VITE_TELEMETRY_COLLECT_ENDPOINT=/api/observability/events
VITE_TELEMETRY_SUMMARY_ENDPOINT=/api/observability/summary

# 只在生产构建且显式启用后注入已有 Vercel 服务。
VITE_ANALYTICS_ENABLED=true
```

两个 telemetry 地址只允许同源绝对路径，不含查询参数。这里的 `/api` 是完整请求路径，查询使用请求核心已有认证能力，不会重复拼接业务 baseURL。未连接全站服务时，页面明确显示“未连接”；请求失败或格式异常不会以本机数字代替全站结果。

采集器不扫描 DOM、点击文本或表单，不记录账号、密码、令牌、公司名称、完整 URL 或查询参数。事件经过字段和动作白名单清洗。记录有容量与时效上限，服务端发布以最多 20 条的小批次异步发送；失败批次丢弃，不无限重试、不补发历史本机记录。

## 服务端接口契约

当前仓库只有前端适配器，没有统计数据库和服务端实现。后端需要完成以下两类接口后，才可在统计页读取其他访客的汇总。

### `POST /api/observability/events`

接收 `{ schemaVersion: 1, events: TelemetryEvent[] }`，字段见 `src/types/observability.ts`。成功返回 204。每个事件有随机 `id`，服务端按 ID 去重，并独立验证白名单字段、时间范围与批次大小；来源、站点、租户归属应由可信服务端确定，不信任浏览器声明。公开演示访问与真实业务访问须分开统计。服务端负责限流、存储保留期和写入可靠性；浏览器发送成功不等于数据已被数据库接收。

### `GET /api/observability/summary?from=<毫秒>&to=<毫秒>`

复用当前认证，服务端核验读取权限与站点/租户范围。返回 `{ code: 0, data: UsageSummary }`，精确契约见 `src/types/observability.ts`，其中 `scope` 必须为 `site`。字段包括总计、自然日趋势、稳定路由名称的排行和 P50/P95、事件类型计数、窗口宽度分布。无需返回任何用户身份或逐条访客明细。

统计日期使用应用所在时区的自然日，接口应按部署约定的时区与请求范围聚合。页面会拒绝缺失字段、负计数、非有限数、异常耗时、重复维度和错误数据范围，并剔除契约之外的附加字段。

## 已有 Vercel 接入

Vercel Web Analytics 与 Speed Insights 仍只在生产且显式开启时工作。Web Analytics 已改为从成功的 Vue Router 导航手动发布，兼容 Hash 路由；事件 URL 使用稳定路由名，避免查询参数和动态路径泄露。自定义事件发布明确的登录结果、公司切换与功能操作，计划需要支持相应能力。

跨访客的 Vercel 报告在其管理控制台查看。启用配置不代表服务已经开通或正在接收数据，也不会自动赋予前端读取管理报表的权限。前端不保存 Vercel 管理凭据。若需要在本统计页展示全站聚合，仍须通过服务端汇总接口或服务端接入 Analytics Drains，再提供上述查询契约。
