# 复合表格业务回归

这组测试消费 RobotAdmin 生产构建和项目锁定的正式 npm 包，在 Chromium、Firefox、WebKit 中连续操作真实产销页面。没有额外的测试路由、表格替身或业务运行时探针。

## 执行

```bash
bun run type-build:tables
bun run build
bun run test:e2e:tables --list
bun run test:e2e:tables
```

`--list` 只检查测试发现，不启动浏览器。浏览器执行前会使用现有环境检查；macOS Codex seatbelt 环境需要通过执行工具对最后一条具体命令使用 `sandbox_permissions=require_escalated`，不能清除环境标记或添加 `--no-sandbox`。

配置单独启动 `127.0.0.1:4188` 的生产预览，避免复用其他任务的服务器。失败 trace、截图和测试附件位于 `node_modules/.cache/table-regression/`，JSON 报告为 `node_modules/.cache/table-regression-results.json`。工作流 `.github/workflows/table-regression.yml` 支持手动运行，在表格及相关产销变更的 PR 上执行；重试为 0，不能把重试成功当作通过。

## 验收链路

| 连续场景       | 断言                                                                                                                                                                                   |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 远程主从工作台 | 动态质量字段与长标题 → 实际拖宽只影响目标列 → 右固定操作列在横滚后仍可命中 → 跨页勾选 → 修改草稿 → 真实 tags 往返 → 字段、列宽、页码、选择和草稿保留 → 查看其他订单详情 → 保存当前订单 |
| 生产计划调度   | 新增弹窗必填校验 → 完成填写与保存 → 末页勾选新记录 → tags 往返 → 逐行编辑正确记录 → 独立详情反映保存结果 → 再次往返仍保留选择与记录数                                                  |
| 账号偏好隔离   | 同一浏览器文档中真实演示登录、退出、换账号；分别调整 C_Table 和 MachTable 列宽，A/B 默认与保存结果分别恢复                                                                             |
| 公司偏好隔离   | 同一账号经公司选择器切换；南京与西安分别调宽，返回后恢复各自偏好，不以刷新代替状态清理                                                                                                 |
| 旧键隔离       | 无身份范围的历史偏好键不会被新会话读取、迁移或覆写                                                                                                                                     |

每个浏览器执行同一套 5 条链路。账号/公司测试复用已有 `table-preference-isolation.pw.ts`，避免维护两套登录与偏好契约。两条新增连续链路检查未捕获脚本异常。标签往返及身份切换直接保存并比较原始 `Document` 对象，完整导航会使旧上下文失效；不使用可能因时间精度或时钟映射变化而波动的 `performance.timeOrigin` 作为文档身份。

两条主从复合链固定为 1720×1200 的左右分栏场景，确保确实发生横向滚动；窄屏和矮屏的自动堆叠由主业务布局用例另外覆盖。Chromium 配置移除 headless 默认的 `--hide-scrollbars`，保留桌面原生轨道，继续检查真实占位、命中与拖动，避免在隐藏轨道的测试环境中误判产品。

## 结果边界

- 首次进入业务页的会话 fixture 只用于前两条交互链；偏好隔离三条测试使用真实演示账号、拼图和公司选择器，不注入测试用户 Store。
- 产销数据及远程工作台响应是项目已有的本地示例/异步模拟。本测试不证明真实后端 CAS、权限校验、幂等、分组汇总或导出快照已验收。
- 公司切换覆盖当前演示中的身份范围；不代表已经验证所有真实租户和权限组合。
- WebKit 回归不能代替真实 Safari、Windows 读屏或旧版浏览器验收。有限链路也不等价于长期堆内存无泄漏。
- 实际通过数量、版本与失败原因以本轮 JSON 报告为准；测试发现或文件存在不能算作浏览器通过。
