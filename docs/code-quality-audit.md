审计对象为当前本地工作区。范围覆盖 58 个编号演示页、6 个产销案例、22 个应用页面和路由入口，共 86 个独立页面入口。另检查了 22 个私有组件入口，包括八种表单布局、PDF 阅读器、MachTable 导入与大数据演示。预览路由复用的业务页按源码入口计一次。

逐页从模板的主要组件和事件向下检查数据所有权、控制器返回口、业务规则、场景配置、异步时序与清理。行数、返回值项数和圈复杂度用于定位，最终按依赖是否有实际用途评估。审计覆盖页面实现及直接相关的组件契约，本轮只对两处行为做定向复现，其余结论来自源码审阅。业务代码保留当前工作区版本。

逐页清单的“缺陷”表示已复现的行为问题，“优先”表示改动经常需要跨多个职责同步，“简化”表示有具体的局部收敛空间，“保留”表示当前实现适合维持其规模。每个页面附可回看的源码位置。
