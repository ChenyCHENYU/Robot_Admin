## 优化前的逐页审计（2026-11-24）

**当前仍有页面未达到代码质量要求。** 对照当前工作区逐项核对了 58 个编号演示页、6 个产销案例和 22 个应用页面及路由入口，共 86 个页面。另核对了 24 个页面私有组件的归属与引入方式。

| 结论 | 页数 | 判定依据                                                                                 |
| ---- | ---: | ---------------------------------------------------------------------------------------- |
| 缺陷 |   11 | 已用当前源码或安装依赖复现，或可由当前模板绑定与处理分支直接确认。复现方式见各页和下文。 |
| 优先 |   10 | 业务数据、异常处理或交互状态存在跨职责耦合，后续修改容易出现遗漏。                       |
| 建议 |   38 | 有可定位的重复定义、无消费者的绑定、样例与实际配置差异或规范问题。                       |
| 保留 |   27 | 实现与页面职责相称，当前证据下适合保留。                                                 |

重点查找同一份业务规则是否多处维护，模板是否为了使用一个功能先接收一组无关属性，公开类型是否能约束实际输入，异步结果能否回到正确的页面状态。场景样例、表格模型和渲染配置靠近各自消费面。一次性纯转换优先写在值的来源处，只有独立生命周期或实质复用才考虑新增 composable 或组件。

### 建议先核查的现象

- **会留下错误数据或错误结果。** 人员批量变更一条成功、一条版本冲突时，页面只报失败且没有重新取列表。裁剪页在新图提交后可能把旧图结果作为当前可下载结果。活动日志的单日筛选包含次日零点。 [批量结果](../src/views/sys-manage/user-manage/useUserManagement.ts#L465) · [导出结果](../src/views/demo/45-image-cropper/useCropWorkspace.ts#L156) · [日期筛选](../src/views/account/activity-log/index.vue#L205)
- **控制项或导出结果和界面描述不一致。** ZIP 的两种模板打包模式实测产出相同；紧凑 JSON 复制写入 `[object Object]`；签名未勾选水印仍给导出组件传启用。拖拽活动列表在重新实例化页面时也会读到上一实例追加的数据。 [ZIP](../src/views/demo/17-export-zip/index.vue#L523) · [JSON 复制](../src/composables/useCopy.ts#L244) · [签名](../src/views/demo/42-signature/useSignatureWorkspace.ts#L47) · [拖拽活动列表](../src/views/demo/20-dragable/index.vue#L316)
- **从调用路径看出责任归属还需要收紧。** MachTable 的本地树仍沿用远端订单加载和 CSV 分支，导入字段与列定义重复；权限治理翻一个分页会加载六组数据，有无关接口失败时整批回写中断。 [MachTable 场景绑定](../src/views/demo/57-mach-table/index.vue#L613) · [CSV 分支](../src/views/demo/57-mach-table/index.vue#L667) · [治理请求](../src/views/sys-manage/permission-manage/usePermissionManagement.ts#L858)

### 自动扫描与复现范围

- 当前 ESLint 覆盖 `src/views` 的 314 个 TS、JS、Vue 文件，0 错误、0 警告。AST 扫描覆盖同一批文件。110 个 Vue 文件均有显式组件名和 TypeScript 脚本，空白占位的组件名是唯一的 PascalCase 例外。扫描还找到 8 个缺少项目文件头的文件和 1 处 `as unknown as` 草稿断言。 [占位组件](../src/views/error-page/blank.vue#L5) · [菜单草稿](../src/views/sys-manage/menu-manage/useMenuManagement.ts#L378)
- 页面私有组件路径均使用 PascalCase，24 个均查到显式引用，页面没有手动导入 `src/components/global` 或 `src/components/local` 下的应用共享组件。组件包供 `h()` 使用的值导入、样式入口与类型导入按实际用途判断。 [自动导入配置](../src/config/vite/viteComponentsConfig.ts#L55)
- 本轮重新运行 `bun run verify`。类型和样式检查、318 项 Bun 测试、197 项组件测试、两套构建及体积预算均通过。全仓 ESLint 有 7 条位于 `src/views` 之外的警告。
- 本轮用当前代码和受控依赖复现了活动日期边界、批量部分成功、裁剪并发、签名水印、ZIP 归档、紧凑 JSON 和拖拽实例状态。工作流旧选择、拖拽排序、步骤末按钮和时间线展开依据模板、处理器及组件公开行为确认。这些检查与上一轮浏览器逐页挂载记录分别保留。
