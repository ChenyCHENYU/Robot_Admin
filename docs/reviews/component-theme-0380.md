# Robot_Admin 组件库 0.38.0 接入复核

## 接入与收敛

- 正式依赖从 0.37.2 升级到 0.38.0；Bun 锁文件保留官方完整性信息，不使用本地组件别名。
- 现有主题 Store、设置 Store 和 NConfigProvider 继续各司其职。项目颜色只在 `src/config/theme/component-colors.ts` 配置；主色和圆角由原设置抽屉提供。
- 最终 Provider 结果单向投影为应用 `--app-*`。移除全局公共 `--c-*` 默认、玻璃风格旧桥接和暗色卡片强制覆盖，保留实例及弹层主题的优先级。
- 表单页使用 C_Density 同步表单布局与操作栏；表格页移除按列位置猜测宽度、控件最小宽度、圆角和缩放的旧样式。
- 搜索页新增正式 C_AutoComplete；组织工作台新增正式 C_UserPicker，复用现有本地目录，支持组织范围、子部门、跨部门选择、确认、取消和清空。
- Navbar、消息预览自有 Teleport 显式携带当前 Provider 颜色；消息详情和页面状态反馈使用已定义的应用角色。

## 静态与类型验证

- 全量样式门禁：123 个 SFC、112 个样式块及全局入口。新增对全局 --c-* 声明和 @property 注册的阻断。
- 应用、Node 配置及组件测试类型检查通过；使用正式安装包和项目 TypeScript 5.8。
- 318 项逻辑测试、177 项组件测试通过。
- 全量 Oxlint 零告警；ESLint 无错误，保留 10 个既有复杂度告警，改动文件定向检查无新增告警。
- MCP 开发依赖的旧 Hono 固定版本升级到官方修复版；安全审计原始告警为零，67 项行为检查通过，实际 MCP stdio 查询通过。没有修改豁免或安全门禁。

## 体积与加载

首屏预加载仍为 90 个，原预算不变。组件的无依赖色板计算并入既有 shared-helpers；主题适配器、编辑器、媒体和图形 SDK 保持自身入口。

本轮构建首屏静态资源 1,261,714 字节；工作前主目录已有产物为 1,255,714 字节，增加 6,000 字节。该对比描述产物字节，不等同于真实网络延迟或运行时性能基准。

## 浏览器验证

本轮执行 167 项 Chromium 生产构建回归，全部通过（既有重点场景 160 项、新增接入 7 项）。

- 从真实菜单提取 86 个页面，连续导航并逐页返回步骤页检查实际文字像素；保留 86 张页面截图。
- 覆盖表单八种布局、密度联动、搜索建议、各表格编辑模式、宽窄屏、树的 2100 节点虚拟化与重试、三表分割及真实 tags 离返草稿。
- 覆盖消息分类、审批/待办独立状态、发送治理、原地换肤、自有 body 弹层、文件与编辑工作区。
- 新增检查自定义品牌/圆角、候选键盘选择/自由输入/清空、组织选人确认/取消/空选，以及三种密度下展开列和序号列的实际间距与子表功能。

这是当前注册页面和所列交互的验收，不是全部浏览器、屏幕阅读器及所有配置排列的认证。

## 覆盖边界

- 全部 58 个演示目录及子布局、产销、系统管理、账号消息、首页、仪表盘、登录与全局组件已按使用范围检查。正常页面不为制造改动而重写。
- 63 个公开组件中，当前源码有 62 个具名静态引用；包含动态导入、类型与配置引用，不能据此声称每个组件的每个组合都经过像素验收。
- 通用 C_NotificationCenter UI 没有直接嵌入应用；当前企业消息工作台保留更完整的分类、待办、审批、发送治理和审计体验，不为增加引用数量替换它。
- 组织选人示例为 14 人本地目录，分页协议已测试；搜索为姓名、部门、职位和工号的连续子串匹配。真实服务接入和拼音分词不属于本轮新增范围。
- --app-* 属于应用全局；嵌套 Provider 对组件本身的语义主题独立生效。第三方外站 iframe 的内部页面不属于本项目视觉验收范围。
- 本轮变更面向单体应用；micro-app、module-federation、monorepo 仅记录通用升级影响，各架构需按自身依赖和构建约定再评估。
